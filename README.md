# HR Интервью

**Android-приложение для проведения структурированного HR-интервью и оценки кандидатов по компетенциям.**

Проект разработан как мобильный инструмент для HR-специалиста: приложение помогает проводить интервью по единой структуре, фиксировать оценки и комментарии и сохранять результаты собеседований.

## Возможности

- проведение структурированного интервью;
- выбор типа интервью и компетенций;
- автоматический выбор 12 вопросов из банка;
- рандомизация вопросов внутри компетенций;
- оценка ответа кандидата по шкале от 1 до 5;
- фиксация комментария HR к вопросу;
- просмотр итогового результата;
- сохранение истории проведённых интервью;
- встроенный банк вопросов;
- настройки приложения;
- адаптация интерфейса под мобильный экран.

## Интерфейс

Приложение выполнено в корпоративной стилистике АО «Людиновокабель».

Использованы фирменные синий, оранжевый и белый цвета, элементы кабельной тематики и собственная иконка приложения.

## Технологии

- Jetpack Compose
- Android SDK
- Gradle
